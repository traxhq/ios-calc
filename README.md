Overview
A beautifully crafted, fully functional calculator built with pure HTML, CSS, and JavaScript that faithfully recreates the iconic Apple iOS Calculator experience. Features the signature clean design, smooth animations, and intuitive user interface that iPhone users know and love.

✨ Key Features

🎨 Authentic iOS Design
Classic iOS 7+ aesthetic with clean, minimalist interface
Gradient button styling matching Apple's design language
Crisp typography using system fonts (San Francisco style)
Proper spacing and proportions mirroring the native iOS calculator layout

⚡ Core Functionality
Basic arithmetic operations: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
Decimal support: Precise floating-point calculations
Percentage calculations (%): Quick percentage operations
Toggle sign (±): Switch between positive and negative numbers
Clear functions:
AC (All Clear): Reset entire calculation
C (Clear): Clear current entry (when applicable)

💫 User Experience
Real-time display: Large, readable number output
Smooth button animations: Press effects with visual feedback
Responsive layout: Adapts to different screen sizes
Keyboard support: Optional keyboard input capability
Calculation history: Shows current operation being performed

🎯 Technical Highlights
Zero dependencies: Pure vanilla HTML/CSS/JavaScript
Lightweight & fast: Optimized performance
Clean code structure: Well-commented and maintainable
Cross-browser compatible: Works on modern browsers
Mobile-friendly: Touch-optimized for mobile devices

Color Scheme:

Number buttons (0-9, decimal): Dark gray (#333)
Operator buttons (+, −, ×, ÷, =): Bright orange (#FF9500)

🎨 Design Philosophy
This calculator prioritizes:

Simplicity: No cluttered scientific functions - just the essentials
Familiarity: Feels instantly recognizable to iOS users
Accessibility: High contrast, clear buttons, large touch targets
Performance: Instant response, no lag
